# Гормолзавод · ҚҰРТ ЫСТАЛҒАН / КУРТ КОПЧЁНЫЙ — 1 кг

Конкурсный проект по AI-дизайну упаковки копчёного курта для ТОО «Гормолзавод» (Кокшетау).

## Концепция

Герметичный дой-пак с зип-замком и выделением копчёного курта. Масса нетто: 1 кг. Предварительный размер лицевой плоскости 200 × 300 мм (вместимость должна быть подтверждена).

## Исследование

10 фото из 3 торговых точек (SPAR, SMALL, небольшой продуктовый магазин), 28 октября 2026 года. Адреса не указаны. Фото получены позже периода, указанного в задании.

## Производство

Предварительная оценка Kupack: 160–180 ₸/шт., минимум 20 000 шт., без индивидуальных кодов. Для второго производителя Konvert24 цена не получена.

## Промо

QR на упаковке ведёт на предложенный лендинг; одноразовый код размещается внутри. Интерфейс и начисление баллов представлены как демонстрационная концепция, не как работающая CRM.

## Доказательные материалы

PDF, фотографии, 10 скриншотов результатов дизайна и производственная переписка включены в полный конкурсный архив (отправляется на Stavleak отдельно).

Работа является дизайнерской концепцией, не утверждённым промышленным макетом.
